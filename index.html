01 / MODELOS FORMALES

Un patrón. Dos autómatas equivalentes.

Estos modelos reconocen códigos de habitación; no representan el lexer completo. Σ = {A–Z, 0–9, =, -, espacio, tabulación, salto de línea}.

AFND-ε · ramas par e impar

n0 H → n1 ε → {n2, n3}
n2 0,2,4,6,8 → n4
n3 1,3,5,7,9 → n4
n4 0–9 → n5 0–9 → n6 ◎

Q = {n0, n1, n2, n3, n4, n5, n6}; inicial n0; F = {n6}. Las transiciones no definidas llevan al conjunto vacío.

AFD · función de transición total

q0 H → q1 0–9 → q2 0–9 → q3 0–9 → q4 ◎

Q = {q0, q1, q2, q3, q4, qr}; inicial q0; F = {q4}; qr es el estado sumidero.

Ejemplos: H203 y H504 se aceptan; H20, H2034, h203 y X203 se rechazan. La aceptación léxica no garantiza existencia en el catálogo.

02 / GRAMÁTICA Y DERIVACIONES

De las producciones a una solicitud.

Orden fijo, cinco campos y fin de entrada obligatorio. Los espacios, tabulaciones y saltos de línea se omiten entre tokens; no dentro de ellos.

            06 / MEDICIONES
            
Datos observados, sin conclusiones anticipadas.

          

          

            Exactitud = casos con validez y tipo de error correctos / 40.
            Detección = entradas inválidas rechazadas / 30. Tiempo = media del
            pipeline, sin renderizado, tras una ejecución de calentamiento de
            cada caso. Consistencia = casos con clasificación idéntica en 10
            repeticiones / 40.
          

          
          
Comparación aún no ejecutada. Ambas implementaciones son automatizadas.

          
Entorno pendiente de medición.

          

            La comparación reutiliza las mismas reglas semánticas con el
            lexer/parser manual original. Diferencias de lenguaje se reportan,
            no se ocultan. No representa un procedimiento humano ni permite
            afirmar mejoras frente a validación manual humana.

Flujo de trabajo

              

                Análisis → diseño → desarrollo → pruebas. JavaScript ES6+,
                ANTLR4 4.13.2, Tailwind CSS, Vite, Vitest y Selenium WebDriver.
                GitHub gestiona las versiones; Vercel sirve el sitio estático.
              

              
npm ci
npm run generate   # Java 11+; solo al cambiar la gramática
npm test
npm run benchmark
npm run build
npm run dev

            

            

              
Alcance

              

                Una SOLICITUD VÁLIDA superó los análisis. No es una RESERVA
                CONFIRMADA. No se ejecuta SQL ni se registran reservas en un
                servidor.
              

              

                El generador y runtime comparten versión. Los archivos generados
                se versionan para que Vercel no necesite Java.
